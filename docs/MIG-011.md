## Resultado

La ficha real tiene galeria e informacion en dos columnas desktop, miniaturas
reubicadas en movil, reserva inline publica, promos condicionales, preview de
menus, recomendaciones aleatorias del mercado y reviews publicas. No tiene
mapa, compartir, descripcion expandible ni CTA booking sticky. Solo las fotos
de reviews abren lightbox; el original tiene un fallo de posicion/foco/cierre.

La documentacion no arrastra Menu, Booking, Auth, likes ni Following. Campos y
seguridad Java/OpenAPI divergentes quedan registrados, sin corregir contratos.
"Destacado" conserva el criterio verificable de primeros dos menus de Angular;
no bloquea el cierre ni se interpreta como curacion editorial del backend.

## Excepcion Explicita: Backend Local

El usuario indico que el backend no esta ni estara desplegado y pidio todos
los servicios locales. AppConfig usa localhost8080 en development/production
y rechaza origins API remotos; tests de configuracion/cliente adaptados.
Este es el unico cambio de runtime de011, separado de la arqueologia documental.
No se edita Angular, Java, router, Home, navbar, DS ni generatedAPI.

Fixtures de navegador no contactan backend real. El bridge web historico es
otra dependencia, no un servicio API: no se valida ni se modifica en A-C.
